# TreZinTheme – VS Code Theme Collection

**TreZinTheme** là bộ sưu tập theme VS Code tập trung vào trải nghiệm code lâu dài, giảm mỏi mắt, nhưng vẫn giữ được độ tương phản rõ ràng cho syntax.

---

## Theme Collection

### TreZin - Night Owl
